# Libras Ao Vivo 5.8

Aplicação HTML independente com reconhecimento de voz quando disponível, consulta e reprodução de vídeos de sinais reais cadastrados e um laboratório de avatar SVG articulado.

## Atenção linguística
O avatar SVG demonstra movimentos de braços/mãos e não contém sinais validados de Libras. Nenhuma sequência salva no editor constitui tradução automática. Para sinais autênticos utilize vídeos autorizados, com validação linguística. A reprodução de sinais isolados não equivale a interpretação contextual.

## Uso
Abra index.html para explorar o laboratório. Para reconhecimento de voz, publique em HTTPS, permita microfone e use navegador com SpeechRecognition; a API pode exigir conexão. Cadastrar vídeos locais depende de IndexedDB. Botões "Adicionar pose", "Reproduzir poses", "Salvar sequência", "Carregar" e "Exportar JSON" controlam apenas animações demonstrativas.

## Privacidade e direitos
Dados locais ficam no dispositivo conforme disponibilidade do navegador. Reconhecimento de voz pode enviar áudio a terceiros conforme o navegador. Faça testes e obtenha autorização dos participantes; verifique licenças de mídias antes de uso comercial.
